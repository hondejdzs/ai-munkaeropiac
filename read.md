# AI Munkaerőpiac – Python adatelemzési projekt

## 1. A projekt bemutatása

A projekt célja a mesterséges intelligencia (AI) munkaerőpiacának elemzése Python programozási nyelv segítségével.

Az elemzés egy Kaggle-ről letöltött adatkészleten alapul, amely AI-állásokkal, fizetésekkel, tapasztalati szintekkel és elvárt technikai készségekkel kapcsolatos adatokat tartalmaz.

## 2. Felhasznált technológiák

- Python
- NumPy
- CSV
- Visual Studio Code
- Kaggle

## 3. Elemzési kérdések

A program öt fő kérdésre keresi a választ:

1. Mennyi az AI-állások átlagos, medián, minimum és maximum fizetése?
2. Hogyan változik a fizetés a tapasztalati szint alapján?
3. Melyek a leggyakoribb AI-munkakörök?
4. Melyik munkavégzési forma rendelkezik a legmagasabb átlagfizetéssel?
5. Melyek a leggyakrabban előforduló technikai készségek?

## 4. A projekt felépítése

- `ai_munke.py` – Python programkód
- `ai_job_dataset.csv` – elemzett adatállomány
- `requirements.txt` – szükséges Python-könyvtárak
- `dokumentacio.md` – részletes projektleírás

## 5. Adatforrás

Kaggle – Global AI Job Market & Salary Trends 2025

https://www.kaggle.com/datasets/bismasajjad/global-ai-job-market-and-salary-trends-2025
